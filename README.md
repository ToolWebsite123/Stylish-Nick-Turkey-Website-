# Stylish Nick Turkey Website

Türkiye pazarı için geliştirilmiş, Next.js App Router, TypeScript ve Tailwind CSS tabanlı şekilli nick ve metin dönüştürme platformu.

## 🚀 Teknolojiler
- **Framework**: Next.js (App Router)
- **Dil**: TypeScript
- **Stillendirme**: Tailwind CSS
- **Paket Yöneticisi**: npm
- **Hedef Bölge**: Türkiye (`tr-TR`)

## 🛠️ Kurulum ve Çalıştırma

Geliştirme sunucusunu başlatmak için:

```bash
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

### Tip Kontrolü ve Derleme

```bash
# TypeScript Kontrolü
npx tsc --noEmit

# Linter Kontrolü
npm run lint

# Üretim Derlemesi
npm run build
```
